# WTP Protos Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the WTP (`canyonroad.wtp.v1` + `ocsf`) protobuf contract out of agentsh into a new public repo `canyonroad/wtp-protos` that ships committed Go *and* Rust generated code, and rewire agentsh to consume the published Go module.

**Architecture:** A standalone public repo holds the `.proto` source plus committed per-language artifacts generated by `buf` with local plugins (no registry/network at gen time). The hand-written validator `validate.go` moves with the schema into the Go module (it *is* part of the contract). Rust gets generated types only. agentsh deletes its in-tree `proto/canyonroad/**`, adds a normal `require` on the new Go module (no `vendor/` dir), and rewrites import paths — package identifiers (`wtpv1`, `ocsfpb`) are preserved so the change is a pure path swap. The agentsh-internal wire-golden test machinery (tethered to agentsh's `fixtures` package) stays in agentsh.

**Tech Stack:** Go 1.25/1.26, `buf` (installed via `go install`), `protoc-gen-go`/`protoc-gen-go-grpc` (Go install), `protoc-gen-prost`/`protoc-gen-tonic`/`protoc-gen-prost-crate` (cargo install), Rust 1.95 / Cargo, `gh` CLI (org: `canyonroad`).

**Key facts (verified against the tree):**
- Protos to move: `proto/canyonroad/wtp/v1/wtp.proto` (pkg `canyonroad.wtp.v1`, `go_package …/v1;wtpv1`) + 8 files under `proto/canyonroad/wtp/v1/ocsf/` (pkg `canyonroad.wtp.v1.ocsf`, `go_package …/ocsf;ocsfpb`). `wtp.proto` does **not** `import` the ocsf files.
- `proto/agentsh/v1/*` (pty, `pkg/ptygrpc`) **stays** in agentsh — untouched.
- 61 agentsh `.go` files import `github.com/agentsh/agentsh/proto/canyonroad/wtp/v1` (and `/ocsf`).
- Hand-written Go in the proto tree: `validate.go` (pkg `wtpv1`) + tests `proto_test.go`, `validate_test.go`, `validate_unknown_test.go` (pkg `wtpv1`), `validate_reason_test.go` (pkg `wtpv1_test`) → **move to wtp-protos**. `wire_generator_test.go` (imports agentsh `…/gen-wire-goldens/fixtures`) + `wire_roundtrip_test.go` + `testdata/*.bin` (13 goldens) → **stay in agentsh** (relocated out of the deleted dir).

**Target wtp-protos layout:**
```
wtp-protos/
  buf.yaml
  buf.gen.yaml
  README.md
  proto/canyonroad/wtp/v1/wtp.proto
  proto/canyonroad/wtp/v1/ocsf/*.proto        # 8 files
  gen/go/                                       # module github.com/canyonroad/wtp-protos/gen/go
    go.mod
    canyonroad/wtp/v1/wtp.pb.go, wtp_grpc.pb.go, validate.go, *_test.go
    canyonroad/wtp/v1/ocsf/*.pb.go
  gen/rust/                                     # crate wtp-proto
    Cargo.toml
    src/...
```

### Task A4: Write buf config

```yaml

```
- [ ] **Step 2: Create `buf.gen.yaml`** (local plugins; Go via source_relative into gen/go, Rust via prost/tonic + prost-crate into gen/rust)
```yaml
version: v2
plugins:
  # ---- Go ----
  - local: protoc-gen-go
    out: gen/go
    opt: paths=source_relative
  - local: protoc-gen-go-grpc
    out: gen/go
    opt: paths=source_relative
  # ---- Rust (prost messages + tonic services), then assemble into a crate ----
  - local: protoc-gen-prost
    out: gen/rust/src
    opt:
      - compile_well_known_types
  - local: protoc-gen-tonic
    out: gen/rust/src
    opt:
      - compile_well_known_types
  - local: protoc-gen-prost-crate
    out: gen/rust
    opt:
      - no_features
      - gen_crate=gen/rust/Cargo.toml
```
